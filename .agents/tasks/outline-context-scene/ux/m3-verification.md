## 5. 未覆盖风险 / 限制

1. **真实模型质量**：回溯不发模型（确定性，质量风险低）；续写只验证了 prompt 结构、Schema 与合成文本，真实模型是否遵守「不替作者决定人物生死/感情/凶手、不提前泄底、不超 2 个新实体」需真机 + 真实 API Key 抽检。
2. **回溯 targetWords 取章节当前字数**（旧稿 260 字/章 → 目标 260 字）：1:1 如实映射，但作者可能误读为「写作目标」；是否需要 UI 标注「按现有字数」交文学顾问判断。
3. **续写落点固定**为「最后一个顶层节点（其下有章节点）」：本演示追加到「第三卷 灯」（只写了 1 章的卷）；长连载若末卷不是当前正在写的卷，作者可能需要手动挪动节点或后续提供落点选择（design 明确本期不做）。
4. 回溯不自动分卷、不建立条目关联（design 非目标）；移动端长列表（10 章预览/大树）可用性由顾问/真机确认。
5. 假模型/假数据：所有续写文案为脚本写死，只评信息与流程，不评假文笔。
