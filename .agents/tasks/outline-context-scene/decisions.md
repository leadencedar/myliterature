# 文墨 · M1 及后续里程碑的产品决策

> 确认时间：2026-10-26 / 2026-10-27
> 来源：用户逐项确认 + 三方评审（产品-流程、产品-架构、文学顾问）交叉讨论结论
> 本文是后续 design/plan 的前提；与旧文档冲突时以本文为准

---

## D1 · 自动关联不静默写回

- 采用细化结果后，在**确认面板**里展示「每个子节点将关联的条目」（可展开看标题、可逐条移除），随采用一并写入。
- 只回填 title/alias 精确命中；上限 8 条/节点；排除 `pinned`（它们始终注入）；继承父节点的显式关联。
- 不做后台静默回填；作者移除过的条目在本次会话内不再建议。
- **理由**：错配比漏配更糟（文学顾问）；静默写回会让显式优先档失真（产品-架构、产品-流程）。

## D2 · 大纲「额外要求」不落库

- 细化面板的「额外要求」保持一次性输入：参与本次名称匹配与注入，不写库。
- UI 提示「要让它影响后续章节，请写进梗概」；输入框在本会话内保留上次内容。
- 代价：`replace` 细化后需要重填；后续若高频再评估加字段（需 Dexie v8 + 备份 v5）。

## D3 · 章节归档：自动出提案、批量确认

- 摘要**逐章即时**生成提案；知识条目提取按 3–5 章组批确认，每章最多 3 条**实质变化**条目，只提有变化的。
- **新登场且开口说话**的具名角色立即单条提案（否则下次出场口吻先漂，补不回来）。
- 章级幂等：重跑只删本章 pending；确定性 batchId；连点不重复。
- 不自动改大纲状态，只提示「可标完成」+ 一键确认；完成时不自弹全屏付费面板；首次开启明示成本。
- 设置项：知识库提取默认**开**（分级如上），可关；摘要始终自动生成提案。
- 理由：用户明确要「自动更新摘要及知识库」；三方一致认为静默落库不可接受。

## D4 · 字数口径

- `targetWords` 有值以其为准；为空默认 3000 字（代码现状的回退行为，M1 起显式展示来源）。
- 续写**不自动**：默认手动「补未落地场景」，沿「大纲 N 场、已写 M 场、缺哪场」提示，不以字数为目标注水。
- 优先结构（场景数/节拍），再做差额与补场景。
- 文体篇幅建议（如网文 2000–3000 字）与节点目标冲突时，以节点目标为准。

## D5 · 自动大纲形态

- 砍掉「多方向推荐故事发展」；故事方向探索交给已有的互动推演。
- 做两个受限模式：
  1. **前沿续写 3–5 章**：只从当前进度往后生成少量章节节点，每章须写冲突、代价、回收哪条伏笔；不替作者定命运。
  2. **导入作品 1:1 轻量回溯大纲**：只用已有章节标题 + 摘要链，节点数 = 章数、可预览删改、单事务建节点并回填 `outlineNodeId`。
- 整本多卷回溯放二期；入口只在「导入作品无大纲」与「大纲写到头」两处。

## D6 · 文风

- 分三期：①锚点 + 四项确定性检测（句长、对话占比、段长、标点/虚词密度；对作者近 3–5 章已完成章节中位数只报骤变，不评分、不落库、会话内提示）→ ②style-check（复用 normCheck 的分段/定位/会话内机制，手动或异常触发）→ ③润色（**不做**）。
- 锚点取作者已确认、含对话的段落（2–3 段），不取 AI 稿；放易变后缀。
- 检测/检查不自动改正文、不落库；不做文风评分，避免制造焦虑。

## D7 · 零迁移

- M1–M4 不新增实体字段、不升 Dexie、不动备份版本。
- 幂等用确定性 batchId + 仓储事务 supersede；摘要过期用现有 `updatedAt` 现算；links 作为 apply/确认面板的运行时数据，不进 schema 与提案 payload。
- 若后续确有高频需求（如章节级文风备注），单独评估迁移，不在本周期。

## D8 · 细化链路修复优先

- 细化前先落盘当前表单，避免「用已保存的旧梗概生成」。
- `replace` 细化二次确认，列出将替换的子节点数与受影响章节数（正文保留、解除大纲关联）。
- 大纲树落库事务化，替换/追加失败不留半棵树。

## D9 · 细纲的写作标准（场景卡）

- 子节点梗概必须包含「谁想要什么 / 什么在阻碍 / 转折点 / 结尾局面或认知变化」。
- 至少一个子节点要让人物在**软肋**或**世界规则代价**上做出选择/拒绝；复述设定不算「应用设定」。
- 判据（反事实）：把软肋/规则换掉，场景应不同；否则设定只是装饰。
- 梗概里用知识库名称/别名点名涉及条目，便于采用后关联；但不许为凑关联硬塞无关人物。

## D10 · T5/T6 排期

- M1：T0 + T2/T3 + T1 结构件与截断防线。
- M2：T1 收尾 + T4-lite。
- M3：T5-lite（前沿续写 → 导入回溯）。
- M4：T6 第一期（锚点+检测）→ 第二期（检查）。
- 明确不做：AI 润色、文风评分、多方向推荐、整本多卷回溯、章节级文风备注。
