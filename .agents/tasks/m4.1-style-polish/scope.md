# M4.1 文风打磨

来源：M4 文学顾问 P2/P3。只做低风险改动，换锚点 UI 留 M4.2。

## 做

1. **锚点优先含对话**：在「已完成章」候选中，优先选开头 600 字段落里含对白（「”"）的最早一章；都没有则退回最早已完成/最早有正文。仍确定性。
2. **注入清单说明**：整章生成「本次注入」含文风锚点时，补一句「只用于对齐语感，不会复述原文」。
3. **severity 标签统一**：差异较大 / 有所差异 / 略有差异（替换「局部差异/轻微差异」，消除范围与程度混轴）。
4. **检查面板成本与边界**：idle 显示「本章约 N 字，检查一次调用」；补一句「只对照风格档案与锚点，不逐个人物核对口吻」。
5. 测试/文案同步；真实模型 live D 不重跑（选择规则变化可能换锚点，但 Schema/Prompt 未变）。

## 不做

- 不做「换锚点」下拉/选章 UI（M4.2）；不做锚点优先含对话的段落窗口（仍从开头取）。
- 不改 style-check schema 字段（只动标签）；不自动改写。

## 验收

- 第一章无对白、第二章有对白 → 锚点选第二章；第一章有对白 → 选第一章；都无对白 → 最早已完成。
- 注入清单出现锚点时显示「只对齐语感」说明；无锚点不显示。
- severity 三档新文案；面板 idle 显示字数与单次调用、边界说明。
- 全量门禁 + QA + 顾问快速确认。
