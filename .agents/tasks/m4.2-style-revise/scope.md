# M4.2 文风检查：定位与按建议改写

> 用户反馈：文风检查完只能看，不能像规范检查那样定位/改。
> 边界不变：不自动写正文、不自动替换；AI 只给建议，写入必须作者在段落加工里确认。

## 做

1. 每条文风 issue 增加两个动作（对齐规范检查）：
   - **定位**：在当前编辑器正文里找到 `excerpt`，选中并关闭文风面板（只看不改）。
   - **按建议改写**：先定位，再打开段落加工面板，预填「rewrite」与「按文风检查建议修改：<suggestion>（依据：<basis>）」；作者仍要点「替换原文」才写入。
2. 定位不到（作者已改过原文）时：按钮禁用并提示「原文已被修改，找不到」。
3. 文风面板关闭后保留本次诊断结果；重新打开仍可逐条定位/改写（与规范检查一致）。
4. 底部文案改为「定位只选中原文；按建议改写会打开段落加工，仍要你确认替换」。
5. 测试：定位回调/选区、按建议改写预填与打开、缺失原文禁用、关闭重开保留、无自动写库。
6. docs 同步（使用说明/产品文档 6.6）。

## 不做

- 不自动应用建议、不批量改、不生成提案；不改 style-check schema/prompt（建议已包含 suggestion+basis）。
- 不做「应用全部」；作者逐条决定。
