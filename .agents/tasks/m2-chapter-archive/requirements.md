# M2 · 章节归档与字数收尾（T4-lite + T1 收尾）

> 状态：待实现
> 用户问题：2（写完自动更新摘要与知识库并标注完成）、3 的收尾（目标差额与补写）
> 前置：M1 已提交（`3e42d25`、`273686c`）；决策见 `.agents/tasks/outline-context-scene/decisions.md` D3/D4

## 目标

1. 作者把章节标为「已完成」后，**自动在后台**生成本章档案：摘要、全书/外传进展、知识库条目更新（可关），全部成为**待确认提案**；不自动弹全屏付费面板，不自动落库、不自动改大纲状态。
2. 知识库条目按 3–5 章一个**归档批次**归组：每章最多 3 条实质变化，新登场的人物条目单独即时提案；同章重复归档幂等（不重复出提案）。
3. 作者可以随时「查看本批档案」，在一处逐条或整批采用；摘要链与知识库因此补全。
4. 大纲节点可完成时只给**提示 + 一键确认**，不自动写。
5. T1 收尾：生成结果与目标差额可见，作者可手动「继续补写」未落地场景；不自动续写到目标字数。

## 非目标

- 不新增 Dexie 表/字段、不升备份版本（批次与设置只存 localStorage）。
- 不做自动采用、不做自动续写、不做自动标完成。
- 不改 M1 的细化/关联逻辑；不改导入链路提示词。

## 验收

- US-A1：标记完成 → 状态行出现「正在生成档案…」→ 不阻塞编辑；成功后显示「本章档案已生成：摘要 + N 条知识库更新待确认 [查看]」。
- US-A2：点「查看」打开本批 ProposalInbox；全部采用后摘要/进展/条目落库；关掉不写。
- US-A3：同一章连续标记完成/草稿/再完成，不产生重复摘要或重复条目提案。
- US-A4：同批 2–5 章的条目提案按名称合并，不出现同名重复；批次满 5 章或超过 24h 自动开新批。
- US-A5：新登场人物（character 分类新条目）即使超过每章 3 条上限也单独出提案。
- US-A6：关闭「自动提取知识库条目」后只生成摘要与进展；关闭「完成后自动归档」后不自动调用，仍可手动补摘要。
- US-A7：章节完成且其大纲节点下所有章节均完成时，编辑器提示「大纲节点可标完成」，点击才写；不自动。
- US-A8：生成结果短于目标 85% 或截断时，显示差额与「继续补写」；补写只续写缺失场景、不重复前文；不自动触发。

## 约束

- 产品原则：AI 产出一律提案确认；失败可重试；未配置模型时提示去设置。
- 成本：归档每章 1 次结构化调用（输入整章、输出摘要+条目）；首次自动运行前在设置页说明。
- 幂等：同章 pending 摘要重建；条目按名称与 pending/已存条目合并；重跑不重复。
- 缓存/基线：归档用 `extract-settings` 任务提示词（可带写作规范 extract 范围）；不改现有任务基线。UI 变更同步测试。
