# 严肃文学作者 · M1+M2 用户测试

## 1. 我是谁

写长篇/中篇，纸刊与出版社，两三年一部；单章 6000–12000 字，常一月磨一场。在意语言质感、结构留白、人物不被因果绑架；反感字数 KPI、AI 腔与流程化。

## 2. 按新功能走一遍

- 细化大纲：**会犹豫**。场景卡四问接近我的写法，但默认拆 5 节，空节点回退 3000，先切成连载节拍。
- 写这一章：**会跳过**。字数、场景数、658/6000 全程在眼，像 KPI 面板；注入清单只给 token，看不到要进 prompt 的说话方式与软肋。
- 标记完成归档：**会用**。不弹窗，只出一条状态行，不打断收工。
- 查看/采用：**会犹豫**。四条折叠一屏，「采用本批（4）」一键落库；摘要是后文唯一记忆，等于让我盲签。
- 继续补写/下一章：**会跳过补写**。触发语仍是「比目标少约 2342 字」；节拍齐了我就标完成。

## 3. 问题清单

1. **P1 字数当导演**：新节点默认 3000 字、细化默认 5 节、「约 3–5 场」按字数反推；结果页用「658/6000」「少约 2342 字」，85% 以下就推「继续补写」，把「短」读成「没写完」。期望默认「不限」，先问节拍是否写完，差额折叠为次要。
2. **P1 归档盲签**：Inbox 默认全折叠，只报「N 项新增」，不显示摘要；「采用本批（4）」把摘要、全书进展（整体替换）、2 个龙套一起写入，状态行却说「2 条知识库更新」。期望默认展开摘要、替换类先看旧→新、计数说全。
3. **P1 留痕只在会话内**：未完成提示点「知道了」即消失，重开只剩「草稿」，看不出半章。期望章节级持久标记，直到手动标完成。
4. **P2 摘要缺「声音」位**：摘要、关键事件、角色、伏笔够用，却无意象与语调落点；后文只继承骨架，声音会被抽干。期望可选「声音锚点」，只放我写的两句。

## 4. 最想要 2 条 / 不要做 1 条

想要：可手改的整段细纲（现已做到，别退回表单）、「声音锚点」进上下文。不要做：把软肋/规则代价与冲突—代价—回收做成每章硬指标或评分。

## 5. 对 M3 自动大纲

会用它：导入旧稿拉 1:1 骨架，找断线、失踪的人；前沿只出 3–5 个「下一步可能」，标明依据章节与未收束张力，全部待确认。绝不接受：自动写大纲、替我定人物生死/关系、把冲突—代价—回收当每章必填、拿模型摘要当唯一事实源、按字数配额切章。

## 6. 一句总评

「不打断、不替我决定」是对的；但默认值与差额话术仍把我当连载作者。字数退为参考、归档成为可读可改的记忆，我才会用它管结构，而不是写字。
