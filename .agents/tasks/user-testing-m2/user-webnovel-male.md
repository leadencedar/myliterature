# 用户测试报告 · 男频连载作者（玄幻/都市异能）

## 1. 我是谁

起点/番茄男频玄幻、都市异能，日更 6000–9000 字，单章 6000 拆 3–5 场。最在意黄金三章、爽点密度、章末钩子。收工不被打断。

## 2. 按新功能走一遍

- **细化大纲**：会用。场景卡有目标/阻碍/转折/结尾与章末钩子。
- **设定注入**：会犹豫。清单只说注入什么，名字关联我不核对。
- **写这一章**：会用。6000 字来自大纲节点、3–5 场参考，默认对。
- **标记完成归档**：会用，不打断（不弹窗、只挂状态行）。
- **查看采用**：会攒着。每章 4 项，日更 2 章每天 4–6 项。
- **继续补写**：会犹豫。不能选补哪场，像让模型凑字数。

## 3. 问题清单

- **P1 细化颗粒度含糊**：「拆成几个子节点」默认 5、提案叫「共 N 章细目」，卡片却写「第1节…约 2000 字」（after-02/03）。我要每章 3–5 场清单；现在一章一张卡，其余场模型自编。期望可选拆到章/场，或每章列 3–5 场（目标/爽点/钩子）。
- **P1 待确认数字口径**：状态行「2 条知识库更新待确认」，收件箱实际 4 项（m2-01/02），我误以为摘要已入库。期望「4 项待确认（含摘要、进展）」，未采用前别写「已生成」。
- **P1 批次只在单章成立**：「查看本批」只在章节状态行；知识库全局收件箱把不同章、不同批和大纲提案混成一列。期望按批/章折叠并保留「采用本批」。
- **P1 继续补写是凑字数**：「还有场景没落地？」下只有「继续补写」，代码里指令仍写「还差约 N 字」、不传缺哪场（m2-08/09）。我想勾「补第3场夜渡」再生成。
- **P2「名字提到」默认全选**：取消只限本次；日更不核对，境界/势力/道具漏关联就漂。

## 4. 最想要 2 条 / 不要做 1 条

想要：① 每章 3–5 场清单，生成/补写按场加载；② 章末钩子单列一行（断在哪、读者在等什么），生成后自检。
不要做：按差额字数自动续写到满、自动补剧情；宁可少写别注水，别动我的一级设定。

## 5. M3 自动大纲

会让它按日更 2 章×6000 的节奏，从已写章+摘要+卷梗概续 3–5 章：每章 3–5 场、一个主冲突、章末钩子类型，标明用到的设定与伏笔，我只改钩子。
绝不接受：直接写正文或直接落库大纲；动金手指、等级体系、主角软肋；每章同一套钩子；一次续 15 章以上；自行收伏笔。

## 6. 一句总评

适合已有粗纲、要稳定日更的男频作者当设定管家+起稿器；但细纲颗粒度、按场补写与钩子自检没到位，日更 6000 的细纲仍得我写。
