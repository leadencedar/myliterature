# M3.2 整章字数校准（软引导 + 超出可见）

> 来源：真实模型抽检 C：目标 1200 字实际 2364 字（197%），`stop` 非截断。
> 用户决定：**不加「不得超过目标 15%」这类硬约束**，不自动压缩。

## 做

1. **软引导**（prompt，不是硬约束）：整章生成要求里加一句——目标字数是篇幅参考；写完若明显超出，优先收紧重复的环境/心理描写、删掉重复信息，不新增无关场景；节拍不足自然收束。保留现有「结构优先、不硬凑」。
2. **超出可见**：结果完成后，字数明显超出目标（>115%）时：
   - 标题「生成完成（超出目标）」；
   - 结果区提示「比目标多约 X 字；采用后可手动删减，或把更紧凑的要求写进『本章额外要求』再生成。不自动压缩，也不硬卡字数。」
   - 不新增模型调用、不自动改写。
3. 100%–115% 仍显示「生成完成」；<100% 保留现状「接近目标」；截断/中断不变。
4. 测试覆盖 90% / 100% / 110% / 120% / 截断；文档同步（产品/使用说明 + 开发计划 M3.2）。

## 不做

- 不加 prompt 硬上限/禁止超过目标；不自动压缩或改写；不新增「收束到目标」按钮（避免变成 AI 润色）。
- 不改短稿/补写逻辑；不改归档/大纲。

## 验收

- 120% 结果有「超出目标」标题 + 提示；110% 无提示；不出现新请求。
- 现有 90%/100%/截断用例不变；全量门禁 + QA 独立断言。
