# 物理真机验收单（M5）

> 目标：在真实手机上确认布局、触摸、软键盘、PWA 安装、真实 API Key 与本地存储行为。
> 服务已在 `http://localhost:5173` 运行（vite host 已开），同一 Wi-Fi 可访问。

## 0. 连接

| 方式 | 地址 |
| --- | --- |
| mDNS（推荐，IP 变了也能用） | `http://star-ai-macro.local:5173` |
| 当前局域网 IP | `http://192.168.1.48:5173` |

- 二维码：`access-qr-local.png` / `access-qr-ip.png`（已打开，可直接扫）。
- 手机与电脑必须在同一 Wi-Fi；首次访问若被 macOS 防火墙拦截，允许 node 传入连接。
- 打不开时：先试 IP 地址；再确认手机 Wi-Fi 未开「客户端隔离 / AP 隔离」。

> **这是新的源（手机 origin ≠ 电脑 localhost）**：手机上的 IndexedDB / localStorage 是空的，API Key 也要在手机上重新填一次；桌面数据不会自动同步。
> 想用真实数据验收：电脑「设置 → 导出备份文件」→ AirDrop 到手机 → 手机「设置 → 选择备份文件 → 覆盖恢复」；然后再填 API Key。

## 1. 加载与安装

- [ ] 手机浏览器打开上述地址，页面完整加载，无白屏/横向滚动条。
- [ ] 底部 Tab 栏在 iPhone 安全区之上，不被 Home indicator 遮住。
- [ ] 「添加到主屏幕」后从图标启动：全屏、图标/名称正确、无浏览器地址栏。
- [ ] 横竖屏切换不破版；返回手势/页面滚动正常。

## 2. 设置与真实模型

- [ ] 「设置」页：DeepSeek 预设默认模型显示 `deepseek-chat`（常规与重点任务）。
- [ ] 填入临时 API Key（不要发到聊天里），点「测试连接」：成功返回文字，显示 token/缓存信息。
- [ ] 故意把模型名改成不存在 → 测试连接给出可读错误；改回 `deepseek-chat` 恢复。
- [ ] 软键盘弹出时 API Key 输入框、保存按钮不被遮挡；收起键盘后可继续操作。

## 3. 主流程（有数据时）

- [ ] 写作页：大纲树/全书进度/互动推演卡片/章节列表均正常；抽屉从底部弹出，不遮 Tab 栏。
- [ ] 点大纲节点 → 「细化」面板：本次注入清单可滚动、token 可见；关闭不写。
- [ ] 生成面板：目标字数/场景数/「文风锚点」说明可见；打开面板不自动发请求。
- [ ] 生成一章（真实模型）：流式正文可滚动、停止按钮可用；结果区字数/目标、选项可点。
- [ ] 标记完成：后台归档状态行不阻断编辑；「查看」打开收件箱；安全提示与「纳入本批」可点。
- [ ] 文风检查：入口可见、无正文时禁用；有正文时一次调用出结果，原文/依据/建议可读，无改写按钮。
- [ ] 自动大纲入口（回溯/规划）在手机上可点，面板不溢出；真实模型耗时/失败提示可读。

## 4. 触摸与输入

- [ ] 长列表（章节/收件箱/注入清单）惯性滚动正常，不误触。
- [ ] 输入框聚焦时软键盘不遮挡当前输入/主按钮；`visualViewport` 变化不把面板顶出屏幕。
- [ ] 按钮点击目标足够大；底部抽屉可下滑关闭（如支持）或点遮罩关闭。
- [ ] 系统深色模式/放大字体下不破版（如设置）。

## 5. 存储与恢复

- [ ] 从主屏图标完全关闭再打开：作品、章节、设置仍在。
- [ ] 手机浏览器隐私模式/清缓存后数据会丢（预期）；提示是否可理解。
- [ ] 导出备份 → 清站点数据 → 用备份恢复：数据回来（API Key 需重填）。
- [ ] 页面刷新后 `localStorage` 的归档批次/写作辅助设置仍在。

## 7. 验收后

- [ ] 删除临时 API Key（设置 → 清除密钥），项目结束后轮换 Key。
- [ ] 关闭开发服务器（启动器窗口 Ctrl+C 或关闭）。

## 已知边界（不是缺陷）

- 手机是独立源，不会自动同步桌面数据；跨设备需备份文件。
- 手机首次打开时没有桌面缓存 Key，需要在手机上重新配置。
- 真机验收不能替代真实模型质量抽检；模型红线（生死/感情/凶手、泄底、实体数量）仍按 live 报告小样本观察。
