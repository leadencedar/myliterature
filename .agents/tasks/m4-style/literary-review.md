# M4 作者视角复核（literary-advisor）

> 依据 `m4-01/02`、`m4-verification.md` §7（未重跑）。假模型只评信息与流程，不评文笔。

**① 锚点：够用，但别只认第一章。** 最早已完成章开头 600 字是合理基线（作者最初定调、只对齐语感）。但中后期语感会变，第一章开头常是定调写景、未必有对白，而漂移最先露在对话里。建议 M4.1 给「换锚点」：默认第一章，可另选已完成章或优先取含对话段落（P2）。

**② 注入清单：够透明，缺一句用途。**「文风锚点 · 第 1 章开头 534」位置对、带 token，能看到被带上。担心「会不会照搬旧文」；建议加一句「只对齐语感，不复述原文」（prompt 有、作者看不到）。P2。

**③ 检查文风：会用，但「明显偏离」最劝退。** 只诊断不改稿、≤5 条、必引原文、对照锚点，我会在 20 章后自查用，末尾「由你决定」也留了决定权。问题是 severity 像判决：演示里被标的那句「他听见自己的心跳，比河声还响」未必是错，作者会觉得「AI 不懂我要的效果」。建议：high 改「可留意/差异较大」，并补一句「与锚点差在哪（叙述距离/句长）」——现在只有建议没依据。P1 低成本，提交前改更好。

**④ 边界：与规范检查要一句区分。**「只给诊断，不改稿」说清了改的边界，但没说与并列的「按规范检查」有何不同。建议面板加一句：文风看语感/叙述距离是否漂，规范看是否违反你定的规矩；并写「依据：风格档案+锚点」。人物声音卡当前没有，口吻靠条目「说话方式」注入；未来做时再明确文风检查不核对单角色口吻。P2。

**⑤ 剩余。** P1：severity 措辞 + 每条差异依据；P2：换锚点、锚点含对话、清单加「不照搬」、规范检查区分、面板显示成本。真机：真实模型误报与说教感、长章一次调用成本。
