# M4 · 文风：锚点注入 + 漂移检查

> 对应问题 6「写着写着文风漂了」；用户测试里严肃文学作者要「声音锚点」，女频要人物声音/关系可见。
> 原则：只读诊断，不自动改写；不新增 Dexie/备份版本。

## 范围

### S1 文风锚点（生成侧预防）

- 整章生成时，自动从**同一线（主线/同一外传）此前已写正文**中选一段作者原文（优先已完成、最早的一章，目标章之前），截取开头约 600 字，作为「文风锚点」放进稳定前缀（风格档案之后、写作规范之前）。
- 注入清单显示「文风锚点 · 第 N 章开头」与 token；作者可以看到它被带到。
- 没有更早正文时（第一章）不注入；锚点只用于对齐语感，明确告诉模型不要照搬情节/句子。
- 纯本地确定性选择，不调模型、不落库、不新增字段。

### S2 文风漂移检查（写后诊断）

- 章节编辑器新增「检查文风」（与「按规范检查」并列）。
- 一次结构化调用，读：风格档案（七维 rubric/文体/额外要求）、文风锚点（若存在）、本章正文。
- 输出：整体判断 + 最多 5 条漂移问题，每条含维度、严重度、原文证据、修改建议；**只诊断，不改稿、不生成提案、不落库**。
- 无问题时明确「未发现明显漂移」；失败可重试。
- 面板关闭不写任何东西。

## 非目标

- 不用 AI 自动改写/润色（D6）；不做评分/排名；不新增 schema 字段或迁移。
- 不改生成正文的 prompt 结构（除了锚点块）；不改摘要/归档链路。
- 不做跨书/名家风格比对。

## 验收

- 整章生成「本次注入」出现「文风锚点 · 第 N 章开头」，顺序在风格档案后、规范前；第一章/无正文无此项。
- 锚点选择确定性；作者编辑早期章节后锚点更新，其余行为不变。
- 「检查文风」一次调用出结果；≤5 条问题；无问题时提示明确；关闭/失败不写库、不出提案。
- 既有 2470 tests 保持；新增测试覆盖选择/顺序/UI/诊断。
