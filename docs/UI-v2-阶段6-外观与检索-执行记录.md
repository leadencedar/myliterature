## 3. 验证

- **测试**：`2621 passed / 5 skipped`（新增 appearance store 3 例、设置页 1 例、章节序搜索 1 例）。
- **类型/格式/构建**：`tsc --noEmit` 0；`format:check` 0；`npm run build` 0。
- **真实 Chromium 1440×900**：
  - 设置切宋体后预览：18px / 36.9px（2.05）/ **720px**，字体栈为 Songti SC 等；
  - 刷新后仍为宋体，`aria-pressed` 保持；
  - 写作工作台正文：**720px / 18px / 36.9px / 40.0 字每行**，无 console/page error。
- **`npm run ui:appearance`** 四组全 PASS：
  - 黑体 17 → 680 / 1.85 / 40.0
  - 宋体 18 → 720 / 2.05 / 40.0
  - 黑体 22 → 880 / 1.85 / 40.0
  - 宋体 16 → 640 / 2.05 / 40.0
  - 均无横向滚动、无脚本错误。
- **默认工作台宽度验收**：`node scripts/ui-width-check.mjs --url .../__workbench` 五档仍全 PASS。

## 5. 当前边界

- 外观偏好只存本机 localStorage，不进备份/IndexedDB；换设备后回到默认。
- 只作用于工作台正文与预览；设置页预览用独立 inline style，不改变全局 UI 字号。
- 黑体 22px 在 1280 视口下可用宽不足 880px，会低于 40 字/行；1440 及更宽才达到 40.0。验收脚本固定 1440，符合 `40×字号` 口径。
- 宋体依赖系统字体回退；不同平台可能回退到 Noto Serif/STSong。
- 编辑器内查找（P1）、全局命令面板（P2）仍不做。
- 真实设备高分屏/字体渲染差异未验收。
