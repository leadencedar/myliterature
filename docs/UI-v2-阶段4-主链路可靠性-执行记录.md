## 1. 做了什么

| 改动       | 文件                                                               | 说明                                                                                                                          |
| ---------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 保存反馈   | `ChapterEditorScreen.tsx`                                          | 成功显示实际 `updatedAt` 的「已保存 · HH:mm」；失败常驻错误条；「重试保存」「导出草稿」；关闭拦截保留                         |
| 版本提示   | 同上                                                               | 单机库没有跨端版本号，状态行明确显示「未检测版本」，不假装有冲突检测                                                          |
| 撤销保护   | 同上                                                               | 撤销栈记录「改前 / 改后」；正文 ≠ 改后基准时禁用整段撤销，改为「查看改前版本」Sheet，可复制 / 另存 txt                        |
| 采用基准   | 同上、`GenerateChapterSheet.tsx`、`ReviseSheet.tsx`                | 生成/加工记录首次建议的正文与选区快照；采用时若正文或选区已变，弹「当前正文已变化」，可查看原文 / 重新生成 / 取消，不静默覆盖 |
| 未审阅建议 | `unreviewedSuggestions.ts`、两个 AI Sheet                          | 关闭面板不丢建议；按章保留在会话内，重新打开面板直接回到结果态；采用后清除，明确放弃也清除                                    |
| 未审阅标记 | `ChapterEditorScreen.tsx`、`WritingPage.tsx`、`WorkbenchShell.tsx` | 编辑器状态行「继续审阅 AI 建议」；工作台页头「待审阅 N」；章节行「待审」                                                      |
| 空章门控   | `ChapterEditorScreen.tsx`                                          | 正文为空时「加工这一段」禁用并说明原因；「生成本章」仍可用                                                                    |

## 3. 验证

- **测试**：`2615 passed / 5 skipped`。
- 新增覆盖：
  - 保存成功显示落库时间；空章加工禁用 + 原因；
  - 保存失败时错误条、导出草稿入口；
  - 采用后继续编辑 → 撤销保护 Sheet；
  - 面板打开期间正文被改动 → 采用冲突拦截，不覆盖后续编辑；
  - 关闭面板后建议按章保留、可继续审阅；
  - `vitest.setup.ts` 在用例间清空会话 store，避免标记串味。
- **类型/格式/构建**：`tsc --noEmit` 0；`format:check` 0；`npm run build` 0。
- **真实 Chromium 冒烟**（1280×900，临时 IndexedDB）：打开章节后状态行为空，空章显示「正文还是空的」原因；输入后状态为「已保存 · 11:30」；「未检测版本」可见；无 console/page error。

## 4. §4 验收对照

| 规格项                          | 状态                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| 保存中/成功·时间/失败可重试     | ✅ 串行队列 + `updatedAt` 时间 + 常驻错误条                                                  |
| 失败导出草稿 / 关闭拦截         | ✅ 错误条与退出拦截都有「导出草稿」                                                          |
| 冲突提示                        | ⚠️ 单机库无版本基准，按规格明确显示「未检测版本」                                            |
| 切章前 flush                    | ✅ 已有；大纲/外传/新建章节切章也先 flush                                                    |
| 未审阅建议保留                  | ✅ 会话内按章保留；采用/明确放弃清除                                                         |
| 生成中切换章节                  | ❌ 尚未保留在飞任务与部分结果（已知边界）                                                    |
| 采用前基准检查                  | ✅ 生成/加工均有正文与选区快照；冲突可查看原文/重新生成/取消                                 |
| 撤销保护                        | ✅ 后续编辑后禁用整段撤销，改前版本可复制/另存                                               |
| 空建议/不完整稿                 | ✅ 沿用现有守卫（空文本不采用、不完整稿二次确认、完成章退回草稿）                            |
| 空章续写禁用                    | ✅ 禁用 + 原因；生成本章仍可用                                                               |
| 纯空格标题                      | ⚠️ 大纲节点已有「标题不能为空」；章节标题允许留空并以「第 N 章」回退显示，本阶段未改成硬错误 |
| aria-live / 焦点 / 手机面板语义 | ⚠️ 保存状态只随状态变化播报；其余焦点/移动语义未在本阶段全量复验                             |

## 5. 当前边界

- 未审阅建议只在内存：刷新后消失（P1 才做跨刷新恢复）；同章生成与加工共用一条建议位。
- 生成/加工进行中切换章节仍会中断当前面板，不保留在飞任务；部分结果只在面板保持打开时存在。
- 采用冲突只比较本地编辑状态与快照；不检测另一个标签页的跨端写入。
- 撤销保护 Sheet 只能复制/另存改前文本，不能自动三路合并。
- 移动端真机键盘/安全区、读屏焦点仍未验收。
