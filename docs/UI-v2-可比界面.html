Q3

右栏「本章」放什么？

已选 B

三种形态的右栏示意（只比较内容，组织方式见 Q5）。A 零数据迁移；B 新增一个作者备忘字段；C 还需要章内节拍模型。A 和 B 都能保留「目标 / 字数 / 资料」；AI 操作的位置由 Q5 决定（推荐回编辑器底栏）。

Q4

右栏叫什么？

已选 B

主导航里已经有「计划」（每日/每周写作目标）。右栏再叫「本章计划」会让手机上出现两个「计划」。名称只影响文案，但会影响帮助、设置和测试。

Q5

右栏怎么组织，浏览才不费劲？

已选 A

右栏的问题是：可编辑信息、只读参考、主操作混在一个 320px 抽屉里，要一路滚动才能看全。三种组织方式，核心区别是「主操作放在哪」以及「右栏要不要承载 AI」。
