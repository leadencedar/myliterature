## 1. 做了什么

| 改动           | 文件                                              | 说明                                                                                                                                   |
| -------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 底部操作栏     | `WorkbenchShell.tsx`、`workbench.css`             | `<768px` 固定 56px 操作栏：**目录 / 上一章 / 下一章 / 本章 / AI**；盖在全局底部 Tab 之上的安全位置                                     |
| 目录 Sheet     | `WorkbenchShell.tsx`                              | 移动端目录从左侧滑层改为底部 Sheet（76dvh），复用章节/大纲 tab、搜索、外传、新建章节；带「关闭」                                       |
| 本章全屏 Sheet | `WorkbenchShell.tsx`、`ChapterPlanPanel.tsx`      | `<1024px` 本章抽屉改为全屏 Sheet（390 宽时铺满），保留目标/资料/备忘/细纲；关闭回正文                                                  |
| AI 菜单        | `WritingWorkbench.tsx`、`ChapterEditorScreen.tsx` | 移动端 AI 按钮打开 Sheet 菜单：生成本章 / 加工这一段；编辑器原底栏在 `<768px` 隐藏，避免两套 AI 入口                                   |
| 选区工具条     | `ChapterEditorScreen.tsx`                         | 选中正文后，在操作栏上方显示「已选 N 字 · 加工选段」；`position: fixed`，不推动正文                                                    |
| 软键盘/安全区  | `WorkbenchShell.tsx`、`workbench.css`             | `window.visualViewport` 计算键盘遮挡并写入 `--wb-keyboard-inset`；shell 用 `dvh`，操作栏随键盘上移；`env(safe-area-inset-bottom)` 避让 |
| 断点拆分       | `workbench.css`                                   | <768 全屏编辑器 + 底部栏；768–1023 保留单栏 + 顶部入口 + 编辑器底栏；≥1024 桌面工作台不变                                              |

## 2. 试用

```bash
git switch feat/ui-v2-stage5
npm run dev
# 浏览器切 390×844，/write 打开一章
# 底部操作栏：目录 / 上一章 / 下一章 / 本章 / AI
# 选中正文：操作栏上方出现「加工选段」
# 点 AI：Sheet 菜单提供生成本章 / 加工这一段
```

真机软键盘只能在设备上最终确认；本环境用视口 + `visualViewport` 代码路径验收。

## 3. 验证

- **测试**：`2616 passed / 5 skipped`（新增移动端操作栏入口用例：目录/上一/下一/本章/AI 菜单）。
- **类型/格式/构建**：`tsc --noEmit` 0；`format:check` 0；`npm run build` 0。
- **真实 Chromium 390×844 冒烟**：
  - 操作栏 `display:flex`，top 728 / bottom 784；全局底部 Tab top 783，贴合不重叠；
  - `.editor-footer` 在移动端 `display:none`，正文无横向滚动；
  - 目录 Sheet：宽 390、底部贴齐、高 416（内容高度）；「关闭」可回正文；
  - 本章 Sheet：宽 390、铺满视口；目标/资料/备忘可见；
  - AI 菜单：Sheet 含「生成本章 / 加工这一段」；
  - 选中正文：选区工具条显示「已选 N 字 · 加工选段」，位置 top 680 / bottom 720，位于操作栏上方且不遮挡正文。
- **断点复核**：768 宽操作栏隐藏、编辑器底栏恢复、本章为全屏 Sheet；1280 宽操作栏隐藏、底栏恢复、本章抽屉 320px。
- **宽度验收**：`node scripts/ui-width-check.mjs --url http://127.0.0.1:5173/__workbench` 五档仍全 PASS。

## 5. 当前边界

- **没有真机**：iOS/Android 软键盘、安全区、系统返回、文本选择菜单只做了代码路径和 Chromium 视口模拟，不能宣称真机通过。
- 移动端顶部工作台页头仍保留推演/导出/章节/本章按钮；与底部栏有重复入口，但功能一致，后续可精简。
- 本章 Sheet 的关闭文案是「关闭」，不是规格里的「返回正文」；行为相同，文案待统一。
- 全屏 Sheet 关闭后依赖 DOM 保留滚动位置；**选区恢复**未做显式测量。
- 320 宽、200% 缩放、读屏未复验。
