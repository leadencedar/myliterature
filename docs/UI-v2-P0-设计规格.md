## 1. P0 目标与边界

**P0 要交付的东西**：一个可评审、可实施的「创作工作台」——桌面两栏（章节栏 + 编辑器）+ 可按需打开的右栏「本章」（含作者备忘）；移动端全屏编辑器 + 底部操作栏。补齐保存/切章/采用/撤销的可靠性反馈，并保留现有全部产品能力。

**P0 明确不做**（放 P1 或另立里程碑）：

- 四态章节状态（沿用 `draft / done` + 空白辅助展示）；
- 可勾选场景节拍（Q3 已选 B「只读信息 + 备忘」，节拍不进入 P0）；
- 暗色模式、品牌色迁移、全局命令面板（Cmd+K 跨实体检索）；
- 右栏固定常驻的三栏布局（P1，17px 下需视口约 ≥1512 才可能保住 40 字/行）；
- 跨刷新恢复编辑位置（P0 只在会话内保持；P1 再定 localStorage/schema）；
- 拖拽排序、章节跨外传移动、批量 AI 生成（沿用现有能力）。

**硬约束**（来自现状与复核反馈）：

- 单套 DOM + CSS 断点，不按宽度渲染两套界面；
- 保存串行队列、退出拦截、提案三方合并、摘要/归档链路不动；
- AI 完整能力不能省（注入清单、目标字数、停止、截断、部分结果、继续补写、采用审阅）；
- CSP 禁止 CDN：图标/字体/样式必须本地内联或打包；
- P0 只新增一个数据字段：`Chapter.note`（Q3=B），需 schema + DB v7→8 + 备份快照 + 测试（见 §8）。

## 3. 布局与导航规格

### 3.1 宽度口径（已按 Q1=B / Q2=A 定）

- 全局导航常驻 **224px**；章节栏 **240px**（1024–1279 变浮层，不占列）；编辑器左右内边距各 **24px**。
- 正文字体：**黑体 17px / 1.85（默认）**；宋体可选（推荐组合 **18px / 2.05**）；字号 16–22 可调。
- 正文 `max-width = 40 × 字号`：默认 **680px**（17×40）；宋体 18px → **720px**；其余字号同理。
- 桌面双栏：`T = 视口 − 224 − 240 − 48 = 视口 − 512`，再取 `min(T, max-width)`。
- 1024–1279（章节栏浮层）：`T = 视口 − 224 − 48 = 视口 − 272`，再取 `min(T, max-width)`。
- 右栏固定三栏（P1）：`T = 视口 − 224 − 240 − 320 − 48 = 视口 − 832`；17px 下需视口约 ≥1512 才达 40 字/行。

### 3.2 断点

| 视口      | 布局                           | 章节栏                      | 正文文本宽（黑体 17px，上限 680）            | 结论                   |
| --------- | ------------------------------ | --------------------------- | -------------------------------------------- | ---------------------- |
| ≥1280     | 双栏：章节栏 + 编辑器          | 常驻 240px                  | 1280 → 可用 768 → 取上限 680px（40.0 字/行） | 达标；更宽屏幕增加留白 |
| 1024–1279 | 双栏：编辑器为主，章节栏浮层   | 默认隐藏，页头/左缘按钮打开 | 1024 → 可用 752 → 取上限 680px（40.0 字/行） | 达标                   |
| 768–1023  | 单栏 + 顶部返回/章节入口       | 浮层                        | 随宽度                                       | 移动优先               |
| <768      | 单栏 + 全屏编辑器 + 底部操作栏 | 底部抽屉                    | 随屏宽                                       | 移动规范见 §9          |

补充：若作者在设置里切换宋体（18px/2.05），`max-width` 变为 720px；1280 双栏可用 768、1024 浮层可用 752，仍能保持 40 字/行。字号每变 1px，`max-width` 变化 40px，验收按设置后的实际值复测。

一致性说明：`lg=1024` 仍是全局导航分界；写作页内不使用 `Page` 的 768/1152 限宽与 `min-h-dvh` 文档滚动，改用 `h-dvh` + 栏内独立滚动（同时保留 `main#main` 与 skip-link）。

### 3.3 工作台结构

```
AppShell（全局导航：桌面侧栏 224 / 手机底部 Tab，均不变）
└─ 写作路由：WorkbenchShell（h-dvh，绕开 Page）
   ├─ 页头（48–56px）：作品名 · 推演 · 待确认 N 项 · 导出 · 本章（右栏开关）
   ├─ 主机区（flex）
   │  ├─ 章节栏 240（≥1280 常驻；以下浮层）
   │  │  ├─ 搜索框（章节检索/跳章）
   │  │  ├─ SegmentedControl：章节 / 大纲
   │  │  ├─ 章节视图：主线分组 + 外传分组 + 新建章节 + 新建外传
   │  │  ├─ 大纲视图：OutlineTreeView（仅样式适配，不改行为）
   │  │  └─ 底部：全书进度（已写/目标/章数）
   │  └─ 编辑器（中栏）
   │     ├─ 标题 input + 状态/保存/字数状态行
   │     ├─ 正文 textarea（居中，max-width=40×字号）
   │     ├─ 选区工具条（固定高度工具带，不推动正文）
   │     └─ 底部动作：加工这一段 · 生成本章 · 检查菜单
   └─ 右栏「本章」抽屉（320px，覆盖式；默认关，状态按设备记忆）
      ├─ 固定头：本章 · 第 N 章 · 字数 · 关闭
      ├─ 折叠区（单列滚动，一次只展开一节）
      │  ├─ 本章目标（默认展开；2 行摘要 + 编辑；来源标注）
      │  ├─ 资料（计数 + 3–5 条 chips + 查看全部 → 知识库）
      │  ├─ 作者备忘（Q3=B；折叠，1 行摘要）
      │  └─ 本章细纲（外传；折叠，1 行摘要）
      └─ 底部：无 AI 表单；主操作固定在编辑器底栏/选区工具条
```

### 3.4 交互与焦点

- 章节栏、右栏抽屉、编辑器三者的滚动互不影响；编辑器滚动位置在会话内保持。
- 打开右栏**不抢编辑器焦点**；`Esc` 只关闭最上层浮层/抽屉，不关闭编辑器（输入法组字时不处理）。
- 章节切换：先 `await flush()`，失败不切；切换后焦点回正文，选区恢复。
- 移动端：全屏编辑器 + 底部操作栏（目录 / 上一章 / 下一章 / 本章 / AI）；面板为全屏 Sheet，带「返回正文」并恢复滚动与选区。

## 4. 写作主链路交互规格（P0 必须完成）

### 4.1 保存反馈

| 状态       | 文案                 | 行为                                                                                                |
| ---------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| 已修改     | 有未保存更改         | 800ms 防抖；继续输入进队列                                                                          |
| 保存中     | 正在保存…            | 串行队列，不并行覆盖                                                                                |
| 成功       | 已保存 · HH:mm       | 用实际落库后的 `updatedAt`；不允许 UI 自己猜时间                                                    |
| 失败       | 保存失败，草稿仍保留 | 常驻错误条 + 重试；提供导出草稿                                                                     |
| 关闭未保存 | 更改尚未保存         | 继续编辑 / 重试 / 导出；明确放弃需二次确认                                                          |
| 冲突       | 此章节已有其他修改   | 对照本地草稿与当前版本，不自动覆盖（若数据层暂无版本基准，P0 明确显示「未检测版本」而不是假装安全） |

- `aria-live` 只在状态变化时播报，不随每次按键重写。
- 正常自动保存不弹 Toast；错误持续可见。

### 4.2 切章与未审阅建议

- 切章前必须 flush；保存失败时留在当前章，提示重试/导出。
- 未采用的 AI 建议**按章保留在会话内**：切走再回来仍在；章节栏/页头显示「有未审阅建议」标记；不提供跨刷新恢复（P1）。
- 生成中切换章节：保留任务引用与部分结果，不静默丢弃；回到该章可继续审阅。

### 4.3 AI 采用与撤销

- **采用前基准检查**：记录目标章节、作用范围、原文基准；采用时若当前正文已变化，拦截并给出「查看原文 / 重新生成 / 取消」；不得静默覆盖。
- **撤销保护**：保存「改前内容 + 改后基准」；若当前正文 ≠ 改后基准，禁用整段撤销，改为「查看改前版本（复制/另存）」；不允许覆盖后续编辑。
- 空建议不可采用；不完整稿采用需二次确认，并在「已完成」章节上自动退回草稿（沿用现有行为）。
- 续写/拼接统一 `trim` 语义，避免前导空行与多余空行（修原型缺陷）。

### 4.4 其他缺陷回归（来自评审 §3.2）

- 纯空格章节标题：字段内报错（不静默返回）；空标题不创建。
- 空章「续写」禁用并说明原因；「生成本章」仍可用（两者语义不同）。
- 选区工具条不推动正文；字数统一口径：正文统计与「已选 N 字」文案分别标注（字符数/去空白字数）。
- 手机切换面板后，当前面板有 `aria-pressed`/`aria-current`，并播报一次；不展示两套正文 DOM。
- 演示文案（「交互样例 · 不保存」）只出现在独立预览，不作为产品文案。

## 5. 右栏「本章」（Q4=B；Q5=A 上下文检查器）

**问题与原则**：第一版把「可编辑信息（目标/备忘）、只读参考（资料/细纲）、操作入口（生成/加工）」堆进同一个 320px 抽屉，导致要一路滚动才能看全，且主操作会随滚动消失。定稿按 Q5=A 调整为「上下文检查器」：

1. **操作跟着正文走**：生成本章 / 加工选段 / 继续补写固定在编辑器底栏或选区工具条；右栏不放 AI 表单。
2. **右栏只做「上下文检查器」**：固定头 + 折叠分组，单列滚动，一次只展开一节，默认展开「本章目标」。
3. **长内容不塞窄栏**：目标/备忘用「2 行摘要 + 编辑」；点编辑就地展开（保存/取消），同时收起其他节；细纲用折叠摘要，展开最多 6 行。
4. **列表不进右栏**：资料只显示计数 + 3–5 条 chips +「查看全部」跳知识库；不在窄栏里搜索长列表。
5. **一处滚动、固定锚点**：无嵌套滚动；右栏头部固定；关闭按钮始终可见。

### 5.1 结构（Q5=A）

```
┌ 右栏「本章」320px ─────────────────┐
│ 固定头：本章 · 第 2 章 · 1,021 字 · 关闭 │
├────────────────────────────────────┤
│ ▾ 本章目标            [大纲梗概] 编辑 │ ← 默认展开
│   让林照发现：信件上的日期，比她收到   │
│   信的日子晚了一天。                  │
│ ▸ 资料 (5)  人物·林照 / 地点·南巷…   │
│ ▸ 作者备忘（Q3=B）     1 行摘要       │
│ ▸ 本章细纲（外传）      1 行摘要       │
│                                       │
│ （滚动区域到此；AI 操作不在这里）      │
└────────────────────────────────────┘
编辑器底栏：加工这一段 · 生成本章 · 检查 ▾
```

### 5.2 分组与交互

| 分组     | 默认状态                   | 摘要行内容                                      | 展开后                                          | 数据来源                                                    |
| -------- | -------------------------- | ----------------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------- |
| 本章目标 | 展开（无目标时收起到空态） | 2 行目标文本 + 来源标签（大纲梗概/外传细纲/无） | 就地 textarea + 保存/取消；保存走编辑器同一队列 | `OutlineNode.synopsis`；外传 `scenarioSource.brief`（只读） |
| 资料     | 收起                       | `资料 (N)` + 前 3–5 个条目名 chips              | 「查看全部」跳知识库条目搜索页                  | `linkedEntryIds`                                            |
| 作者备忘 | 收起（Q3=B，固定包含）     | 1 行摘要 + 字数提示                             | 就地 textarea + 保存/取消                       | `Chapter.note`（P0 新增字段）                               |
| 本章细纲 | 收起（仅外传）             | 1 行摘要                                        | 只读，最多 6 行 + 「在正文中查看」              | `scenarioSource.brief`                                      |

- 手风琴：一次只展开一节；切换时其余自动收起；展开/收起状态存 localStorage。
- 键盘：`↑/↓` 在分组标题间移动，`Enter/Space` 展开，`Esc` 收起当前组（再按才关右栏）；焦点始终回到分组标题。
- 页头「本章」按钮显示状态点：有未保存备忘/资料变更时可见；右栏关闭时不影响 AI 任务。
- 右栏宽度 320px；默认关闭；打开状态存 localStorage（不进备份）。
- 1024px 以下变全屏 Sheet，结构相同；底部「返回正文」回编辑器并恢复选区/滚动。
- 右栏不做第二个「保存」系统：所有写入走编辑器同一保存队列与数据层契约。
- **作者备忘边界**：P0 唯一新增字段；不进入 AI prompt、章节摘要、检索与导出，只在本机与备份里保存。
- **不做**：右栏内嵌 AI 表单、右栏长列表、右栏内二次滚动区域、两个「保存」按钮。

### 5.3 备查：未采用的组织方式（B/C）

- B（右栏标签页）：右栏保留 AI，用「本章 / 资料 / AI」三个页签分隔；适合「不想离开右栏就能发起生成」的作者，代价是模式切换与 tab 内滚动。
- C（极简右栏 + 固定操作条）：右栏只留目标摘要，底部固定「生成本章 / 加工选段」；资料/备忘收进「更多」或知识库。适合最少浏览，代价是资料可达性下降。
- 无论哪种，**「一次只扫一列、主操作不移出视口、列表不塞窄栏」这三条不变**；本次按 A 执行。

## 7. 视觉与设计令牌（P0）

- **品牌色不变**：保留 `paper/ink/seal/accent` 现状；不迁移到设计稿棕色（D6 不在本轮）。
- 新增语义令牌（沿用现有值，只补缺口）：`success / warning / danger / focus / motion-fast / motion-panel`；控制按钮 36px、触控 44px。
- **修正两个现存对比度问题**：`ink-300` 用于占位/加载文字（约 2.55:1）改用 `ink-500` 或加深；11px 选中导航的 `seal` 文字（约 3.86:1）改用 `ink-900` 文字 + `seal` 图标/底色。
- 正文：**黑体 17px / 1.85（默认，桌面与移动一致）**；宋体可选（推荐 18px / 2.05）；正文宽度 `max-width = 40 × 字号`（17px→680、18px→720），窗口变宽优先加两边留白。
- 标题：章节标题 26–28px；工作台视图补 `h1`（作品/工作台名）与 `h2`（区块），修正原型「工作台无标题层级」的问题。
- 焦点：全局 `:focus-visible` 2px `seal` + 3px offset；原型/新组件不得只依赖浏览器默认。
- 动效：120ms hover、180ms 抽屉；尊重 `prefers-reduced-motion`。
- 暗色：P0 不做（无令牌、无验收；不做「技术上有、规格没有」的中间态）。

## 9. 移动端规格

- 壳：全局底部 5 Tab 不变（书架/知识库/写作/计划/设置）；进入写作工作台后，编辑器全屏，底部固定操作栏：**目录 · 上一章 · 下一章 · 本章 · AI**（44px，安全区避让）。
- 目录：底部全屏 Sheet（章节/大纲切换、搜索、外传、新建章节）；选择后回到正文并恢复位置。
- 本章 / AI：底部全屏 Sheet，带「返回正文」；返回时恢复滚动与选区，不回到章首。
- 键盘：使用 `dvh` + `visualViewport` 处理软键盘；输入位置可见；操作栏不被键盘顶飞；尊重安全区。
- 文本选择菜单：不与应用选区工具条抢事件；选区工具条固定在操作栏上方，不遮挡选文。
- 手机不依赖侧滑切章；不使用顶部任务标签第二套导航。
- P0 验收：iPhone/Android 各一台真机（或等效模拟 + 真机复核）、320/390 宽、软键盘、系统返回。

## 14. 风险与后续

- **Q1=B（黑体默认）**：会改变现有阅读手感与所有截图/文档；必须同时提供宋体切换，且切换后按「40×字号」重算 `max-width`（17→680、18→720），两种组合都要复验行长与对比度。
- **Q3=B（作者备忘）**：P0 唯一数据增量；schema + DB v7→8 + 备份快照 + 恢复测试必须同批完成；`note` 明确不进入 AI/摘要/检索/导出，避免后续语义漂移。
- **Q2=A**：1024–1279 依赖章节栏浮层保住 40 字/行；浮层的打开/关闭、焦点与 Esc 逐层行为要单独验收；如果真实浏览器测量低于 39 字/行，再考虑收窄章节栏。
- **Q5=A**：右栏只做上下文检查器，AI 主操作在编辑器底栏；若真实使用中发现「看资料时想就地生成」，再评估 B 方案，不提前塞回右栏。
- **右栏固定三栏（P1）**：17px 下需视口约 ≥1512 才达 40 字/行，不作为 P0 承诺。
- **数值口径**：本文宽度为 CSS 计算（可能受滚动条、字体回退、缩放影响），验收以真实浏览器测量为准；P0 开工前先跑阶段 1 的空壳测量，确认 40 字目标。
- **不在 P0**：四态、可勾选节拍、暗色、品牌色迁移、全局命令面板、跨刷新编辑位置、固定右栏三栏。
